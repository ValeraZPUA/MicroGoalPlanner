# MicroGoal Planner

Android-приложение (Kotlin, MVVM) для планирования финансовых целей через микро-этапы.

## Что уже подготовлено
- Базовый каркас проекта под Android (Gradle Kotlin DSL).
- Структура модулей и пакетов под MVVM.
- Навигация с `BottomTabNavigation` на 5 разделов: Home, Goals, Stages, Analytics, Settings.
- Экран прелоадера с инициализацией и переходом в онбординг.
- 2 экрана онбординга.
- Базовые доменные модели, правила валидации и заглушка планировщика напоминаний.
- Светлая тема с акцентами `#2563eb` и `#ff9800`.
